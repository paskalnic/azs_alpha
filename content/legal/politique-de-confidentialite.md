## Données récoltées et utilisation de celles-ci

Dans le cadre de l’utilisation du site internet, l’éditeur est amené à collecter des données personnelles relatives aux utilisateurs du site internet.

– Formulaire de demande de devis :

- Données collectées :leprénom, le nom, la raison sociale, l’adresse mail et le numéro de téléphone

Ces données sont nécessaires pour contacter la personne, pour lui dresser un devis puis une facture. Elles sont conservées au maximum 10 ans.

– Formulaire de message rapide :

- Données collectées :leprénom, le nom, la raison sociale, l’adresse mail et le numéro de téléphone

Ces données permettent de contacter ultérieurement la personne. Elles sont conservées au maximum 10 ans.

## Mesures de sécurité pour assurer la protection des données personnelles

Les données saisies par l’utilisateur dans les formulaires sont cryptées par le certificat SSL Let’s Encrypt (protocole https).

Les données récoltées via les formulaires sont conservées dans le serveur de messagerie sécurisé de SiteGround mail.

Les données relatives aux commentaires sont conservées dans la base de données du site chez l’hébergeur SiteGround Hosting Ltd.

Tout utilisateur peut :

- Retirer son consentement

- Accéder à ses données

- Les modifier

- Demander à les effacer

- Demander à les transférer vers un tiers (« droit à la portabilité »)

Pour ce faire l’utilisateur doit en faire la demande à l’adresse mail suivante : azs.alphaformations@gmail.com

N° de téléphone de contact : 0690 757 226

En cas de faille de sécurité des données recueillies, la CNIL sera informée dans les 72 heures.
